# Book CRUD

แอปพลิเคชันแสดงโปรไฟล์ที่ทันสมัยและมีการโต้ตอบ สร้างขึ้นด้วย **React Native** และ **Expo Router** สามารถแสดงข้อมูลส่วนตัว, การศึกษา, สกิล, และเข้าถึงคลังหนังสือได้

---
## ✨ ฟีเจอร์หลัก
ลงชื่อเข้าใช้งาน / สมัครสมาชิก
- ระบบ Token-based auth เก็บด้วย `AsyncStorage`
- รีไดเรกต์ไปหน้า Login หากยังไม่ได้รับอนุญาต
- แสดงโปรไฟล์นักศึกษา พร้อมรูปและรหัสนักศึกษา  
- แสดงข้อมูลการศึกษาและสกิล  
- สลับโหมด Dark/Light Mode 
- ลิงก์ไปยังหน้า **เกี่ยวกับรายวิชา** และ **คลังหนังสือ**  
- สร้างหนังสือใหม่
- ดูรายละเอียดหนังสือ
- แก้ไขหนังสือที่มีอยู่
- ลบหนังสือ พร้อมยืนยันก่อนลบ
- ฟอร์มตรวจสอบข้อมูล

### ติดตั้ง dependencies

```bash
npm install
```

### รันโปรเจกต์

```bash
npx start
```
